Privacy Policy

This policy describes the File Compass desktop application's Google Drive integration. The developer is Jan Rathouský (Rathousky.pro), contact jan.rathousky.kladno@gmail.com.

Data accessed and purpose

When you connect your Google account, File Compass requests access to your Google Drive files and folders, including names, paths, identifiers, sizes, modification times and file contents needed for your operations. This enables browsing existing folders, previews, downloads, uploads, copying, renaming, moving and deletion as requested by you. Full Drive access is requested because access only to files created or individually selected for this app would not support browsing your existing Drive as a file manager.

Authorization and local storage

You sign in through Google's authorization page in your browser. File Compass does not receive your Google password. OAuth authorization tokens are retained in an encrypted rclone configuration on your computer. The key is protected for your Windows user account using Windows Data Protection. Account profiles and local operation history may include names, paths and transfer information. Downloaded or copied files remain in the locations you choose; temporary local copies may be used for previews or transfers.

Sharing and transfers

File Compass uses rclone as a helper running locally. API requests go to Google to carry out your operations; file data may also go to a destination you explicitly choose, such as another storage account or network server. File Compass does not operate a publisher server that receives your Google authorization tokens or Drive contents. We do not sell Google user data, use it for advertising, or use it to train generalized artificial intelligence or machine learning models. We do not provide publisher access to your Drive files.

Retention, deletion and control

Local authorization data is retained until you remove the cloud account from File Compass. You can revoke authorization at any time in Google Account third-party connections. Revocation stops future authorized API access; it does not delete files already downloaded. Remove local downloads, temporary files and operation history separately if you no longer need them. Removing an account does not delete files on Google Drive. File deletion on Drive occurs only through file operations you request.

Google API Limited Use

File Compass's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This static website is hosted by GitHub Pages. We do not add analytics, advertising scripts or tracking cookies. GitHub processes technical request information as the hosting provider under its Privacy Statement.

Questions and changes

For questions about File Compass or this policy, contact the developer using the email above. Do not send passwords or authorization tokens. Changes will be published here with an updated date.
