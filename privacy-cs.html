Ochrana soukromí

Tyto zásady popisují integraci Google Drive v desktopové aplikaci File Compass. Vývojářem je Jan Rathouský (Rathousky.pro), kontakt: jan.rathousky.kladno@gmail.com.

Přístup k datům a jeho účel

Po připojení účtu Google žádá File Compass přístup k souborům a složkám na vašem Google Drive, včetně názvů, cest, identifikátorů, velikostí, časů změn a obsahu potřebného k provedení vašich operací. To umožňuje procházení existujících složek, náhledy, stahování, nahrávání, kopírování, přejmenování, přesouvání a mazání podle vašich pokynů. Úplný přístup k Drive je požadován proto, že přístup pouze k souborům vytvořeným nebo jednotlivě vybraným pro tuto aplikaci by neumožnil procházet stávající úložiště jako ve správci souborů.

Přihlášení a místní uložení

Přihlašujete se na autorizační stránce Google v prohlížeči. File Compass vaše heslo Google nezískává. Autorizační tokeny OAuth jsou uloženy v šifrované konfiguraci rclone na vašem počítači. Klíč je chráněn pro váš uživatelský účet pomocí Windows Data Protection. Profily účtů a místní historie operací mohou obsahovat názvy, cesty a informace o přenosech. Stažené či zkopírované soubory zůstávají v umístění, které zvolíte; pro náhledy nebo přenosy mohou vznikat dočasné místní kopie.

Sdílení a přenosy

File Compass používá rclone jako místně spuštěný pomocný program. Požadavky API směřují ke Googlu za účelem provedení vašich operací; data souborů mohou být přenesena také do cíle, který výslovně zvolíte, například na jiný účet úložiště nebo síťový server. File Compass neprovozuje server vydavatele, který by přijímal vaše autorizační tokeny Google nebo obsah Drive. Uživatelská data Google neprodáváme, nepoužíváme k reklamě ani k trénování obecných modelů umělé inteligence či strojového učení. Vydavateli neposkytujeme přístup k vašim souborům na Drive.

Uchovávání, odstranění a vaše kontrola

Místní autorizační data se uchovávají do odebrání cloudového účtu z File Compass. Oprávnění můžete kdykoli odvolat v připojeních třetích stran v účtu Google. Odvolání zastaví budoucí autorizovaný přístup k API; nesmaže již stažené soubory. Místní stažené soubory, dočasné soubory a historii operací odstraňte samostatně, pokud je již nepotřebujete. Odebrání účtu nesmaže soubory na Google Drive. K jejich smazání dochází pouze prostřednictvím operací, které si vyžádáte.

Omezené použití Google API

Používání informací získaných z Google API aplikací File Compass a jejich předávání do jiné aplikace se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

Dotazy a změny

S dotazy k File Compass nebo těmto zásadám se obraťte na vývojáře na uvedené e-mailové adrese. Neposílejte hesla ani autorizační tokeny. Změny budou zveřejněny zde s aktualizovaným datem.
